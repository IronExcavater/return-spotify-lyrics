# Tokens

Each token is a CSS variable on `:root`, and its class reads the variable. To change the look, override the variable. The values on this page are live, so they show an override.

The theme removes Tailwind's colours, text sizes, radii and shadows. Tailwind's spacing, font weights and easings stay.

## Background

`bg-*` reads `--background-color-*`. Tint and shade are see-through, so their swatches show them over `bg-raised`.

<Panel>
    {[
        ['default', 'The page'],
        ['raised', 'One level up: cards, inputs'],
        ['overlay', 'Above the page: popovers, menus, dialogs'],
        ['tint', 'Lightens any background: hover'],
        ['tint-strong', 'Lightens more: selected items'],
        ['shade', 'Darkens any background: press'],
        ['shade-strong', 'Darkens more: behind dialogs'],
        ['accent', 'Primary actions, checkboxes and sliders'],
        ['accent-strong', 'Primary actions on hover'],
        ['negative', 'Destructive actions'],
        ['negative-strong', 'Destructive actions on hover'],
        ['inverse', 'The opposite of default: the play button'],
    ].map(([name, use]) => (
        <Token
            key={name}
            name={`bg-${name}`}
            value={readToken(`--background-color-${name}`)}
            use={use}
        >
            <Swatch variable={`--background-color-${name}`} />
        </Token>
    ))}
</Panel>

<Panel>
    {[

        ['accent', 'Links and active items'],

    ].map(([name, use]) => (
        <Token
            key={name}
            name={`text-${name}`}

            use={use}

            <span
                className="rounded-small px-1 text-x-large"
                style={{
                    color: `var(--text-color-${name})`,

            >

        </Token>
    ))}
</Panel>

## Text size

`text-*` sizes read `--text-*`, and each one also sets a line height and a weight. A `font-*` class changes the weight.

<Panel>
    {[
        ['text-small', 'Metadata and small print'],

        ['text-large', 'Track names and headings'],
        ['text-x-large', 'Lyric lines'],
        ['text-xx-large', 'Page titles'],
    ].map(([name, use]) => (
        <Token
            key={name}
            name={name}
            value={`${readToken(`--${name}`)} / ${readToken(`--${name}--line-height`)}, ${readToken(`--${name}--font-weight`)}`}

        >

</Panel>

## Override a token

Set a variable on `:root` to change it everywhere, or on one element to change it for that element and its children:

```css
:root {
    --background-color-accent: #509bf5;
    --text-color-accent: #509bf5;
}
```
